# ArtBox Quantum 🎨📦
**The File Manager that Understands Creatives**

> PSD, AI, BLEND, C4D previews + AI search + Gallery view

### Why ArtBox?
FileBrowser is for sysadmins. ArtBox is for designers, photographers & 3D artists.

- 🎨 **PSD Preview with layers** - view .PSD/.PSB
- 🧠 **AI Search** - search "red logo" or "beach photo" 
- 🖼️ **Portfolio Gallery** - Pinterest-style view
- 💬 **Client Approval** - share link, get comments
